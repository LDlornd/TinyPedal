# TinyPedal 中文分支

TinyPedal 是开源的模拟赛车遥测叠加显示工具。本分支默认使用简体中文，并保留上游的游戏接口、预设结构和文件格式。上游详细说明见 [英文 README](README.md)。

## 从源码启动

推荐使用 Windows、Python 3.10 和项目指定的 PySide2。Python 版本较新时，上游提供 PySide6 启动选项，但需要另行确认依赖兼容性。此分支没有增加第三方依赖。

在仓库根目录执行以下准备命令。它们会下载子模块、创建本地环境并安装依赖，请自行决定何时执行：

```powershell
git submodule update --init --recursive
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

准备完成后启动：

```powershell
.\.venv\Scripts\python.exe run.py
```

原有游戏仍需按英文 README 配置共享内存或 UDP 接口。叠加层通常需要游戏使用无边框或窗口模式。

LFS 请阅读 [Live for Speed 接入说明](docs/lfs.zh-CN.md)，其中包含可直接填写的游戏配置、数据范围和验证步骤。

## 中文界面与预设

- 在“设置 → 界面语言（重启生效）”切换简体中文或 English，切换后程序会保存并重启。
- 主窗口、托盘菜单、配置标签、常用工具、表头和确认提示使用中文。游戏名称、技术缩写、单位及配置中的枚举值保留原文，方便与游戏和上游文档对照。
- 配置项可以用中文名称或原始英文键搜索；将鼠标停在标签上可查看英文键。
- 预设名称、驾驶者姓名、车辆组别、路书、用户填写的文字及原有仪表自定义文案保持原样。可在对应组件设置中修改叠加层文字。
- 数值输入仍使用小数点，文件中的键和单位不会随界面语言变化，已有预设可继续读取。

翻译集中在 `tinypedal/i18n.py`：完整句子和专用术语放在 `TEXT`，组合配置标签的词表放在 `WORDS`。动态文案先翻译模板，再填入路径、预设名等数据，避免修改用户内容。新增界面请沿用 `tr("文案")`；配置格式化继续调用已有的 `format_option_name`。

## 验证范围

本次仅做源码和 Git diff 静态复核，没有安装依赖、启动界面、构建或运行测试。未执行测试，由用户自行验证。

启动后请核对：中文菜单和标准按钮正常显示；配置项能用中文及英文键搜索；右键预设、仪表和地图时操作仍对应正确功能；切换 English 后能够重启并显示英文。建议用新建预设验证保存、重新加载和切换语言，原有预设可保留作对照。
